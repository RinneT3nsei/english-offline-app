# Offline English — Android додаток для вивчення слів та фраз

Повністю автономний (100% офлайн) мобільний додаток для вивчення англійської лексики з транскрипцією IPA, частинами мови, контекстними реченнями та нативним озвученням через Web Speech API.

## Основні характеристики

- **100% Offline & Безпека**: жодних зовнішніх CDN, шрифтів чи сторонніх бібліотек. Усі скрипти, стилі, іконки (SVG) та словник вбудовані у збірку додатку.
- **Стек**: чистий HTML5, CSS3, ES6+ JavaScript, упаковані в гібридний Android-додаток за допомогою **Capacitor 7**.
- **Dark Slate / OLED дизайн**: комфортна контрастна тема для очей зі збереженням батареї.
- **Швидкий живий пошук**: миттєва фільтрація як за англійським словом чи його частиною, так і за українським перекладом, частиною мови або контекстом.
- **IPA-транскрипція**: точна фонетична транскрипція для кожного слова.
- **Сучасний стиль Google Material You (Material 3)**:
  - Компактні картки зі зменшеною висотою для зручного перегляду великої кількості слів.
  - **Компактні елементи озвучки**:
    - Овальні чіпи **🇺🇸 US** та **🇬🇧 UK** з іконкою динаміка праворуч від транскрипції слова.
    - Вбудовані круглі міні-кнопки з прапорцями **🇺🇸** та **🇬🇧** у правому нижньому кутку блоку цитати.
  - **Функціонал "Обране" (Favorites)**:
    - Зірочка в правому верхньому кутку кожної картки зі збереженням у `localStorage`.
    - Швидкий фільтр **"⭐ Збережені"** у верхньому меню для повторення вибраних слів.
  - **Режим самоперевірки (Blur перекладу)**:
    - Кнопка **"Тренування"** у верхній панелі приховує український переклад легким розмиттям.
    - Тап по перекладу відкриває або знову приховує переклад для тренування пам'яті.
  - Постійно зафіксована компактна шапка у стилі **Material 3**:
    - `position: sticky; top: 0; z-index: 1000;` з напівпрозорим блюром (`rgba(15, 23, 42, 0.85)` + `blur(16px)`).
    - Тонка нижня межа (`border-bottom: 1px solid rgba(255, 255, 255, 0.08)`) та відступ під виріз камери `padding-top: max(12px, env(safe-area-inset-top))`.
    - Список карток плавно йде під заблюрений хедер при скролі без ламання прилипання.
  - Мінімалістичний статус-бейдж **"● 100% Offline"**.
- **База слів**: 55 ретельно дібраних якісних слів рівнів B1–C2 з реальними прикладами вживання та перекладом (`www/assets/dictionary.json`).
- **CI/CD Автоматизація**: готовий робочий процес GitHub Actions (`.github/workflows/build-apk.yml`), який самостійно збирає `Offline-English-APK` на Ubuntu, Java 21 (Zulu), Node 22 та Android SDK.

```text
├── www/                        # Офлайн веб-додаток (чистий HTML/CSS/JS)

│   ├── style.css               # Темна тема (Dark Slate/OLED), адаптивність
│   ├── app.js                  # Логіка пошуку, фільтрів та синтезу мовлення

├── package.json                # Залежності Capacitor 6
└── .gitignore
```

## Локальний запуск та тестування

### 1. Тестування веб-частини у браузері
Ви можете протестувати інтерфейс локально, просто відкривши `www/index.html` через будь-який локальний сервер (наприклад, `npx serve www` або розширення Live Server у VS Code).

### 2. Ініціалізація та білд для Android локально

Потрібно мати встановлені Node.js 18+, JDK 17 та Android Studio з Android SDK:

```bash
# Встановлення залежностей Capacitor
npm install

# Додавання Android платформи (якщо запускається вперше)
npx cap add android

# Синхронізація веб-файлів www/ в проєкт Android
npx cap sync android

# Відкриття проєкту в Android Studio
npx cap open android
```

В Android Studio натисніть кнопку **Run** або виконайте збірку APK через меню: `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`.

Також можна зібрати APK з консолі без відкриття Android Studio:
```bash
cd android
./gradlew assembleDebug
```
Готовий файл з'явиться за шляхом:
`android/app/build/outputs/apk/debug/app-debug.apk`

## Автоматична збірка APK через GitHub Actions

1. Завантажте цей репозиторій на GitHub (`git push origin main`).
2. Перейдіть на вкладку **Actions** вашого GitHub репозиторію.
3. Оберіть workflow **Build Android APK** та натисніть кнопку **Run workflow** (або він запуститься автоматично при push).
4. Після завершення роботи у розділі **Artifacts** завантажте готовий `Offline-English-APK` і встановіть його на свій Android-смартфон.
